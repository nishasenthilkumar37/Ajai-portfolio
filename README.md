# Ajaikanth Saravanan - Anime / Manga AI & Data Science Portfolio

A black-and-white manga-inspired portfolio website built for **Ajaikanth Saravanan**, AI & Data Science Engineer.

---

## 🌟 Highlights & Features

- **Cinematic Manga Entrance**:
  - Pure black background with original anime character illustration in techwear hoodie.
  - Glowing floating energy ring and manga speed burst rays.
  - Interactive "Tap to Zoom / Click to Enter" transition: camera zoom, motion blur, and a 1.5s `"BUILDING..."` cyber diagnostic animation.
  - Replay button in the navigation bar to replay the entrance anytime.

- **Split-Screen Manga Hero**:
  - **Left**: Bold Syne & Space Grotesk typography, typewriter role rotation, tags (`AI • Full Stack • Java • Python • Open Source`), and interactive action buttons (`Resume`, `GitHub`, `LinkedIn`, `Contact`).
  - **Right**: 3D interactive tilt manga character card with glowing aura, scanline HUDs, and manga stickers.

- **8 Comprehensive Chapters / Sections**:
  1. **About**: Prologue & Engineering philosophy with portrait card and core pillars.
  2. **Skills & Stack**: Interactive category filtering across AI/ML, Programming, Data Science, and DevOps with animated proficiency bars.
  3. **Experience**: Manga storyboard timeline featuring AI/ML roles and quantifiable achievements.
  4. **Projects**: Flagship AI systems (OmniVision, NexusAI Agents, DeepInsight Forecaster, NeuralDoc RAG, AutoFlow, CyberPulse) with interactive modal previews and GitHub links.
  5. **Achievements**: Power-level badges for Hackathon 1st Place, Kaggle Expert, Open Source Stars, and Academic Gold Medals.
  6. **Certifications**: Verified credential cards (AWS ML Specialty, DeepLearning.AI, GCP Data Engineer, Oracle Java SE, CKA).
  7. **Education**: B.Tech in CS & Engineering (AI & Data Science Specialization, CGPA 9.2) and published research paper.
  8. **Contact & AI Terminal**: Transmission form + embedded interactive `ajai-bot` mini-terminal simulator.

- **Manga SFX & Web Audio API**:
  - Floating dynamic comic action words (ドドド, ゴゴゴ, バァン, シュッ) on click.
  - Built-in Web Audio synthesizer for futuristic click and zoom sounds (toggleable).
  - Ambient particle and speedline canvas.

## 🚀 Running Locally

Open `index.html` directly in any web browser, or launch a local server:

```bash
# Using Python
python -m http.server 3000
```
Then visit `http://localhost:3000`.
